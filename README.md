Plotly Data Visualization Challenge

Interactive data visualization project built using Plotly and Plotly Express, exploring global development data from the Gapminder dataset.

🔗 Live Demo:
https://ndenizkoroglu.github.io/plotly-visualization-challenge/

 Project Overview

This project demonstrates multiple data visualization techniques using Python and Plotly, focusing on real-world data analysis and interactive storytelling.

The project includes:

Distribution analysis using Boxplots

Correlation analysis using Scatter plots

Time series analysis using Line charts

Grouped and stacked visualizations

Bubble charts with multidimensional encoding

Animated visualizations using time as a dimension

The final result is a fully interactive animated visualization showing:

GDP per Capita vs Life Expectancy (All Years)

With:

Color encoding by continent

Bubble size proportional to population

Time animation across decades

 Key Insights Explored

Relationship between economic development and life expectancy

Evolution of global development trends over time

Regional disparities across continents

Population-weighted impact in global analysis

The animation allows users to visually explore how countries evolve economically and socially over decades.
